# Contributing

Thanks for your interest. Kenwarf is in an early preview, so things move fast.

- **Bugs and ideas:** open an issue. For security problems see [SECURITY.md](SECURITY.md).
- **Pull requests:** keep them small and focused, include tests, run `npm ci && npm run build && npm test` before pushing.
- **Welcome areas:** importers for more systems, test questions for your industry (evaluation suite), translations, documentation.
- **Dependencies:** runtime dependencies only under MIT, Apache-2.0, BSD or ISC (`npm run lizenzen` checks this).
- **Test data:** only made-up companies and people. Never commit real customer data, secrets or internal URLs.
- **License:** by contributing you agree that your contribution is licensed under AGPL-3.0-only.

Code comments and the UI are mostly German; English issues and PRs are fine.
