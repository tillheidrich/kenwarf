# Security Policy

Kenwarf is preview software under active development. Only the latest commit on `main` receives fixes.

## Reporting a vulnerability

Please do **not** open a public issue. Email **info@tillheidrich.de** with:

- what you found and where (file, endpoint, version or commit)
- steps to reproduce or a proof of concept
- the impact you expect

You will get a reply within 7 days. Please give us reasonable time to fix the issue before disclosing it. There is no bug bounty.

Deutsch: Sicherheitslücken bitte vertraulich per Mail an info@tillheidrich.de melden, nicht als öffentliches Issue.
