# Glossar

| Wort | Was wir damit meinen |
|---|---|
| Aufmaß | Termin beim Kunden zum Messen, Beraten, Fotografieren |
| Montagekiste | beschriftete Kiste je Auftrag mit allen Kleinteilen |
| Restekiste | Plattenreste im Lager, sortiert nach Stärke |
| Montagsrunde | Montag 7:15 Uhr, zehn Minuten an der Tafel, Wochenplan |
| Werkstattliste | Liste aller Aufträge mit Status, hängt an der Tafel und liegt digital im Büro |
| Kundenwunsch | eine Zeile im Aufmaßblatt in den Worten des Kunden |
| Eingang | Ort im Wissensordner, an dem Neues landet, bevor es freigegeben ist |
| Freigabe | Jörn oder Sabine sagen ja, dann kommt es in den Ordner |
| Quartalsdurchgang | einmal im Quartal schauen Sabine und Jörn alle Seiten mit altem Stand durch |
